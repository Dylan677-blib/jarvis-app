JARVIS – installierbare Web-App

WICHTIG:
Eine normale HTML-Datei aus der Dateien-App kann auf dem iPhone nicht zuverlässig
als installierbare App mit Service Worker und Mikrofon laufen. Diese Version ist
als PWA vorbereitet.

So installierst du JARVIS auf dem iPhone:
1. Lade den kompletten Ordner auf einen HTTPS-Webserver (z.B. GitHub Pages, Netlify
   oder einen anderen HTTPS-Host).
2. Öffne die Adresse in Safari.
3. Tippe auf Teilen → Zum Home-Bildschirm → Hinzufügen.
4. Starte JARVIS danach über das neue JARVIS-Symbol.

Die App speichert den lokalen Chat im Browser. Die aktuelle Version enthält noch
keine externe KI-API; unbekannte Fragen werden lokal beantwortet.
